# 핫 앤 콜드: 숨겨진 보물을 찾아라! (Hot & Cold)

격자판에 숨겨진 보물의 좌표를 클릭 힌트로 추리해 찾아내는 웹 미니 게임입니다.
스테이지를 클리어할수록 맵이 커지고, 골드로 스킬을 사서 콤보·피버·도감까지 노려볼 수 있습니다.
HTML, CSS, JavaScript만으로 만들어졌으며 별도 설치 없이 브라우저에서 바로 실행됩니다.

## 게임 방법

1. 격자 중 원하는 칸을 클릭하면, 보물과의 맨해튼 거리(Manhattan Distance)에 따라 칸의 색이 바뀌고 힌트가 표시됩니다.
   - 🔴 매우 뜨거움 — 1~2칸 이내
   - 🟠 따뜻함 — 3~4칸 이내
   - 🔵 차가움 — 5칸 이상
2. 보물(★)을 찾으면 스테이지 클리어! 남은 기회를 모두 소진하면 게임 오버가 되며 보물 위치가 공개됩니다.

### 스테이지별 맵 & 기회

| 스테이지 | 격자 크기 | 기본 기회 |
| --- | --- | --- |
| Lv.1 | 6x6 | 8회 |
| Lv.2 | 8x8 | 7회 |
| Lv.3 이상 | 10x10 | 6회 |

### 골드 & 스킬

- 스테이지 클리어 시 **기본 50G + (남은 기회 × 10G)** 를 획득합니다.
- 골드로 스킬을 구매해 탐색을 도울 수 있습니다 (스킬당 한 판에 1회만 사용 가능).
  - 🔍 **레이더 스캔** (30G, Lv.1+) — 클릭한 칸 기준 3x3 범위 내 보물 존재 여부 확인 (기회 소모 없음)
  - 📡 **행/열 탐지** (50G, Lv.2+) — 보물이 있는 가로줄 또는 세로줄 중 하나를 무작위로 표시
  - 💖 **기회 충전** (40G, Lv.3+) — 남은 기회 +2회 즉시 충전
- 골드가 부족하거나 레벨 조건을 만족하지 않으면 스킬 버튼이 비활성화됩니다.

### 콤보 & 피버 모드

- 스테이지를 연속으로 클리어할 때마다 `Combo x N`이 올라가고, 콤보가 높을수록 클리어 골드 보상이 늘어납니다 (콤보 1당 +50%).
- 실패하면 콤보는 0으로 초기화됩니다.
- **2연승 이상** 유지 중이면 다음 스테이지 시작 시 보물이 있는 대략적인 구역(좌상단/우상단/좌하단/우하단)을 미리 알려주는 🔥 피버 모드가 발동합니다.

### 칭호 & 보물 도감

- 지금까지 클리어한 최고 스테이지에 따라 칭호가 자동으로 올라갑니다: 견습 탐험가 → 노련한 탐험가 → 마스터 탐험가 → 전설의 트레저헌터.
- 스테이지를 클리어하면 레벨별 고유 보물(예: Lv.1 🧭 낡은 나침반, Lv.3 🏆 황금 성배)을 도감에 등록합니다. "📖 보물 도감" 버튼으로 수집 현황을 확인할 수 있습니다.
- "다시 시작"을 눌러도 칭호와 도감 수집 기록은 유지되며, 스테이지/골드/콤보만 초기화됩니다.

## 실행 방법

`index.html` 파일을 브라우저로 열기만 하면 바로 플레이할 수 있습니다.

```bash
open index.html
```

또는 로컬 서버로 실행:

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 파일 구조

- [index.html](index.html) — 게임 화면 마크업 (상태창, 스킬 바, 도감 패널 포함)
- [style.css](style.css) — 레이아웃, 색상 피드백, 반응형 스타일
- [script.js](script.js) — 스테이지 진행, 골드/스킬, 콤보/피버, 칭호/도감 로직

## 기술 스택

Vanilla HTML / CSS / JavaScript (프레임워크·라이브러리 없음)
