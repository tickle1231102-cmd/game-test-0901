# 핫 앤 콜드: 숨겨진 보물을 찾아라! (Hot & Cold)

10x10 격자판에 숨겨진 보물의 좌표를 클릭 힌트만으로 추리해 찾아내는 웹 미니 게임입니다.
HTML, CSS, JavaScript만으로 만들어졌으며 별도 설치 없이 브라우저에서 바로 실행됩니다.

## 게임 방법

1. 10x10 격자 중 원하는 칸을 클릭합니다.
2. 클릭한 칸과 보물 사이의 맨해튼 거리(Manhattan Distance)에 따라 칸의 색이 바뀌고 힌트가 표시됩니다.
   - 🔴 매우 뜨거움 — 1~2칸 이내
   - 🟠 따뜻함 — 3~5칸 이내
   - 🔵 차가움 — 6칸 이상
3. 최대 **7번**의 기회 안에 보물(🟡)을 찾으면 승리합니다.
4. 7번을 모두 소진하면 게임 오버가 되며 보물의 위치가 공개됩니다.
5. "게임 초기화" 버튼으로 언제든 새 게임을 시작할 수 있습니다.

## 실행 방법

`index.html` 파일을 브라우저로 열기만 하면 바로 플레이할 수 있습니다.

```bash
open index.html
```

또는 로컬 서버로 실행:

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 파일 구조

- [index.html](index.html) — 게임 화면 마크업
- [style.css](style.css) — 레이아웃 및 색상 피드백 스타일
- [script.js](script.js) — 보물 위치 생성, 클릭 처리, 승패 판정 로직

## 기술 스택

Vanilla HTML / CSS / JavaScript (프레임워크·라이브러리 없음)
